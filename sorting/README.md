مرتب‌سازی (Sorting)
۱. تعریف
مرتب‌سازی فرایند قرار دادن عناصر یک مجموعه در یک ترتیب مشخص، مانند صعودی یا نزولی است.
۲. کاربرد
- مرتب کردن اعداد
- مرتب‌سازی اطلاعات و داده‌ها
- آماده‌سازی داده‌ها برای جستجوی سریع‌تر
۳. پیچیدگی زمانی
الگوریتم	پیچیدگی زمانی
Bubble Sort	O(n²)
Selection Sort	O(n²)
Insertion Sort	O(n²)
Merge Sort	O(n log n)
Quick Sort	O(n log n) میانگین

۴. سؤال نمونه: مرتب‌سازی اعداد
تعدادی عدد دریافت کنید و آن‌ها را به ترتیب صعودی مرتب کنید.
